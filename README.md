# Atharva Komati — Portfolio Website

A multi-page developer portfolio website designed for **Atharva Komati**, featuring **21st.dev** component aesthetics and **UI/UX Pro Max** design principles.

## 🌟 Features

- **Multi-Page Architecture:**
  - `/` — Hero with role cycler, live status in Pune, 21st.dev Bento Grid, and featured projects.
  - `/projects` — Searchable & filterable project gallery with deep-dive architecture modals.
  - `/experience` — WebMobi360 internship breakdown, TPN platform metrics, and MIT-WPU academic history.
  - `/skills` — Interactive categorized tech matrix with proficiency gauges and project mappings.
  - `/terminal` — Interactive Developer CLI with custom commands (`whoami`, `skills`, `projects`, `sudo hire`).
  - `/resume` — High-fidelity digital resume with instant Print-to-PDF formatting and plaintext export.
  - `/contact` — Interactive contact suite with instant copy-to-clipboard and message dispatcher.
- **Visuals & Aesthetics:**
  - Dark obsidian obsidian theme (`#07080d`), electric cyan and indigo glows, frosted glassmorphism panels, and interactive canvas particle backgrounds.
- **Tech Stack:**
  - React 18, Vite, React Router 6, Tailwind CSS, Lucide Icons, Canvas Confetti.

## 🚀 Running the Project

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
